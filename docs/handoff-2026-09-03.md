## Careful

- `thread.turn.start` from the Prompt key sends a real user message to the selected thread.
- The selected thread is the deck's own notion (newest active, or what you scrubbed to),
  not the thread focused in the app — there is no API for app focus.
- Revoke the deck's session in T3 Code Settings → Connections if the session file leaks.
